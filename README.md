# Agent Commission Pro

A responsive frontend implementation of the Agent Commission System shown in the supplied reference images.

## Included
- Dashboard
- Agent Management (CRUD-style add flow)
- Commission Structure and tier rules
- Commission Calculation
- Commission Payouts
- Agent Performance
- Commission History
- Reports + CSV export
- Login / Logout
- Create Account
- Settings
- **New section: Commission Forecast**
- Responsive mobile sidebar
- Light/dark mode toggle
- localStorage-based demo persistence

## Run
Open `index.html` in a modern browser.

Demo login:
- Email: admin@commissionpro.com
- Password: admin123

## Important
This is a frontend-only implementation. Login, accounts and data use browser localStorage for demonstration. For production, replace authentication with a real backend, hashed passwords, sessions/JWT, server-side authorization, validation and a database.
